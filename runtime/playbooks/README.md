# Runtime Playbooks

These playbooks describe the optional runtime layer.

They may overlap conceptually with core Agent Team playbooks, but they are scoped to orchestration, workers, containers, GitHub integrations, local runtime setup, and implementation planning.

Canonical reusable workflow playbooks live in:

```text
agent-team/playbooks/
```

Use the core playbooks for normal Markdown-first Agent Team usage.

Use this folder only when building or operating the optional runtime system.
