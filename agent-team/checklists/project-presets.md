# Project Presets Checklist

## Purpose

Use this checklist when selecting or reviewing a project preset.

---

## Checklist

- [ ] preset is based on project-local signals or explicit human choice
- [ ] selected preset file exists under `agent-team/presets/`
- [ ] default Skills map to existing entries in `agent-team/skills/registry.md`
- [ ] validation defaults match available project tooling or are marked as expectations
- [ ] review gates reflect the project shape and task risk
- [ ] preset does not override repository instructions, human instructions, or safety rules
- [ ] preset does not claim human approval or merge permission
