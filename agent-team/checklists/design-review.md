# Design Review Checklist

## Purpose

This checklist helps reviewers validate user-facing UI and UX changes.

---

## User outcome

- [ ] The intended user goal is clear
- [ ] The main path is easy to follow
- [ ] Labels and copy are understandable
- [ ] Success, empty, loading, and error states are considered

---

## Accessibility

- [ ] Keyboard use is not worsened
- [ ] Focus behavior is reasonable
- [ ] Contrast and text size are acceptable
- [ ] Interactive elements have clear labels

---

## Responsive behavior

- [ ] Layout works on expected desktop sizes
- [ ] Layout works on expected mobile sizes
- [ ] Text does not overlap or overflow
- [ ] Important actions remain reachable

---

## Visual quality

- [ ] Spacing is consistent
- [ ] Hierarchy is clear
- [ ] Existing design conventions are followed
- [ ] Screenshots or manual evidence are included when useful

---

## Escalation

Escalate to UX / Design Reviewer if:

- [ ] the main user flow changes
- [ ] accessibility risk appears
- [ ] visual evidence is missing for a meaningful UI change
- [ ] the change affects onboarding, forms, navigation, or high-use screens
