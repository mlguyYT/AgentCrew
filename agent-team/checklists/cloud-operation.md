# Cloud Operation Checklist

- [ ] Human confirmed the cost-bearing action.
- [ ] Resource purpose, owner, provider, and region are recorded.
- [ ] Resource ID or name is recorded when safe.
- [ ] Public endpoint or access boundary is recorded.
- [ ] Teardown command is written before or immediately after creation.
- [ ] Stop condition or review window is documented.
- [ ] Deletion was verified after teardown.
- [ ] Remaining active resources are called out in the final summary.
- [ ] No secrets, tokens, private paths, local auth commands, raw customer data, or long logs are stored.
