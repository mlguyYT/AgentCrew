# PR Preparation Checklist

## Purpose

Use this checklist before presenting agent-prepared work for human PR approval.

---

## Checklist

- [ ] current task or clear request exists
- [ ] implementation readiness is clear or the blocker is documented
- [ ] test evidence is present or the gap is documented
- [ ] review evidence is present when risk requires it
- [ ] specialist evidence is present when triggered
- [ ] dependency, supply-chain, compatibility, rollout, and migration gates are represented when relevant
- [ ] pending human-only decisions are surfaced
- [ ] risks are separated from blockers
- [ ] suggested PR description is factual and does not claim human approval
- [ ] merge remains a human-only action

---

## Status Options

```yaml
status:
  - ready_for_human_review
  - blocked
  - draft
```
