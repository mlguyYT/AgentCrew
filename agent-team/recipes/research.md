# Research Recipe

## Use For

Source-backed questions, option comparisons, current information, standards, market or vendor evaluation, and uncertain technical decisions.

## Default Route

```text
Researcher Agent -> Product Manager if decision needed -> Human
```

## Agent Focus

- use primary or authoritative sources where possible
- separate facts, assumptions, inferences, and recommendations
- state confidence and open questions
- stop when the decision is ready
- avoid making final human decisions inside the report

## Required Template

```text
agent-team/templates/research-report.md
```
