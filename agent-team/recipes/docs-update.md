# Docs Update Recipe

## Use For

README, guides, examples, changelog, release notes, comments intended as documentation, and public usage instructions.

## Default Route

```text
Documentation Agent -> Reviewer if behavior claims changed -> Human
```

## Agent Focus

- keep instructions current and executable
- make paths and command examples match real files
- avoid overexplaining internals in public quick-start material
- update examples when behavior or usage changes
- preserve AgentCrew terminology consistently

## Escalate When

- docs describe security-sensitive behavior, migrations, public APIs, or release/rollout steps
