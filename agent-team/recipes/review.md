# Review Recipe

## Use For

Code review, PR review, architecture review, risk review, or quality review.

## Default Route

```text
Reviewer -> Specialist Reviewer when triggered -> Human
```

## Agent Focus

- lead with blocking findings
- separate non-blocking risks, preserved legacy issues, test gaps, product decisions, and next phase
- cite file paths and line references when possible
- avoid low-value style comments
- route implementation rework back to Developer

## Required Template

```text
agent-team/templates/review-report.md
```
