# Portfolio Project Recipe

## Use When

Use this recipe for portfolio, resume, interview, case-study, target-role, or job-description-driven project planning.

## Default Handling

```text
Product Manager
  -> Researcher Agent if job evidence is needed
  -> Human scope approval
  -> Developer
  -> Tester
  -> Documentation Agent
  -> Human
```

## Evidence

Produce only the artifacts needed for the decision:

- role-fit matrix
- MVP scope
- resume bullets
- demo script

## Scope Rule

Every feature must prove a hiring signal. If a feature is impressive but does not map to the target role, defer it.

## Human Approval

The human approves the target role, MVP scope, and any public claims before implementation or publication.
