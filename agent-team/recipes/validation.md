# Validation Recipe

## Use For

Testing, QA, regression checks, acceptance validation, and verification requests.

## Default Route

```text
Tester -> Reviewer when risk is meaningful -> Human
```

## Agent Focus

- map validation to acceptance criteria
- run focused tests first, then broader checks when risk requires
- evaluate integration-test need when behavior spans modules or external systems
- report commands, pass/fail, failures, limitations, and recommendation
- document coverage gaps when tooling exists but target is unmet

## Required Template

```text
agent-team/templates/test-report.md
```
